# Reading list starter

A small Python/Streamlit project for testing the orchestrator.
The app currently displays a starter screen.

Use BRIEF.md as the planning request. The feature implementation should add book entry,
status changes, filters, and SQLite persistence.

Run the starter with an environment containing Streamlit:

```sh
python -m streamlit run app.py
```

The orchestrator's “Try sample project” action copies this folder into an independent,
ignored working directory under plans/samples so you can experiment.
